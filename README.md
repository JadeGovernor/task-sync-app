# 效率任务 · 三端同步器（PWA）

V53：创意 / 计划 / 行动三层导航 + 日历 + 七天日程 + 今日统一提醒，
在 2 台 Mac + 1 台 iPhone 间通过 GitHub 私有仓库同步。早期产品定稿见
**[PRODUCT-V2.md](./PRODUCT-V2.md)**，实际行为以本 README 为准。

## 架构

- **代码仓库（公开）**：`JadeGovernor/task-sync-app`，纯前端 PWA，由 GitHub Pages 托管，不含个人数据。
- **数据仓库（私有）**：`JadeGovernor/task-sync`，只存 `tasks.json`、`checkins.json`、`settings.json`。
- 每台设备在「设置」页粘贴一个**只限该私有仓库的 Fine-grained Token**；Token 只存在本机浏览器。
- 离线可看可改：改动先落本机并进入待同步队列，联网后自动补传；静态资源由 Service Worker 缓存。

> GitHub 免费套餐不支持私有仓库发布 Pages，所以代码与数据分仓：代码公开托管，数据留在私有仓库。

## 本地预览

```bash
python3 -m http.server 8123
# 打开 http://127.0.0.1:8123/
```

也可以双击 **`启动本地服务.command`**；手机同一 Wi-Fi 下可访问 `http://<Mac的IP>:8123/`。

## 导航

- **创意层**：点子（沿用旧创意数据）、娱乐（独立 `kind=fun`，与点子互不覆盖）。
- **计划层**：排期、项目、日历、循环。
- **行动层**：日程、打卡（沿用旧自律数据）。
- **今日**：按当天时间聚合所有需要行动的内容。
- **更多**：所有旧页面仍保留，旧入口已统一改名；新导航页面直接复用原数据，不复制、不覆盖。

三个大椭圆只负责展开分组，本身不切页；点击展开后的「点子 / 娱乐 / 排期 / 项目 / 日历 / 循环 / 日程 / 打卡」才进入对应页面。

## 今日的顺序

从上到下固定为：

1. **今日提醒**：所有富文本白纸里标了 `⏰日期`、今天到期或已过期的行；过期项排最前。
2. **今日循环**：只在当天命中的循环任务，勾完沉到底部并标「本周已完成」。
3. **今日打卡**：每日 / 每周打卡；每日漏勾会顺延到今天并标「昨日未打卡」。
4. **近七天项目**：已逾期项目固定排最顶部，其余收结束日在未来 7 天内的项目。
5. **近七周日历**：只收今天起 7 天内的日历记录，可点开直接修改。

提醒和行动项都可以直接在今日页打勾。富文本提醒打勾后，原白纸里对应整行会删除，并保留撤回入口。

## 日历与七天日程

- **日历**支持本月、三个月、十二个月三档；十二个月固定为 4 行 × 3 列。
- 今天有明确标记；有记录的日期显示绿点。点任意日期可连续添加多条记录，回车保存。
- 日历下方按「离今天最近 → 最远」列出全部记录，可编辑、删除。
- **日程**是今天起共 7 张按日期绑定的富文本纸；初始一行，可无限向下写，自动保存。
- 跨天后，前一天没写完的内容会滚到当天最前面，加粗标「昨天剩下内容：」，原文后移并留出两行间距。

## 排期、项目、循环、打卡

- **排期**：只读月历 + 本月四周排期表；周范围可编辑，排期纸自动保存。
- **项目**：已逾期项目不会消失，会顶到最上面并标「已拖延 N 天未完成」；未来 7 天结束的项目进入今日。拖到硬规则冲突位置时会 toast 说明原因。
- **循环**：每周固定日期出现；只在「今日循环」提醒一次，公司旧页不再重复提醒。
- **打卡**：复用旧自律页；只在「今日打卡」提醒一次，今日页不再重复渲染旧自律区块。

## 富文本白纸

支持标题 / 字号 / 高亮 / 字色 / 加粗、选中文字后的快捷格式圆钮、表格行列选择器、
粘贴图片、流程图、撤销 / 重做。白纸支持 `⏰YYYY-MM-DD` 提醒语法，可给一行单独设置或修改提醒。

适用范围：琐事、点子、娱乐、日程每天一张纸、排期底稿、周报。

## 已完成与清理

- 已完成项默认收成一行并沉底，不会在页面顶部继续占空间。
- 不会自动删除历史；设置页可手动清理完成超过 30 天的公司任务与项目方向。
- 清理不影响 `checkins.json`、打卡连续天数与历史记录。

## 同步与数据安全

- 每次改动是一条操作：先拉云端最新内容，叠上本条，再整份写回。
- GET 强制 `cache:'no-store'`；写入撞车（409 / 412 / 422）自动重拉重试，失败操作带退避，不堵后续队列。
- 云端覆盖本机前，会保留最近 20 份本机快照；设置页「数据恢复」可整份回滚三端。
- Token 只存本机，不写入仓库；仓库只保存任务数据，不保存凭据。
